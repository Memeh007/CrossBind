# Examples

Use any public PDB (e.g. from RCSB) as receptor and a small SMILES such as `CCO` (ethanol) for a smoke test once Vina is installed.

Suggested first run:
- Receptor: a pocket-centered protein PDB
- Ligand SMILES: your compound of interest
- Box: set center to the orthosteric / known ligand site; size ~20 Å
